About CineRL

CineRL applies Q-learning to MovieLens 1M. Each state is a preferred genre and satisfaction level; each action is a genre. The saved agent is used for inference only.

State → Action → Recommendation → Reward → Next state → Policy update

Built for clarity

Recommendations exclude movies seen in the training split and are ordered using training-only popularity. The application uses Flask, Pandas, NumPy, HTML, CSS, and JavaScript.
